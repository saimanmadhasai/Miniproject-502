# Clean Drinking Water Monitoring Platform

A Python-based project that analyzes water quality data to assess whether drinking water is safe, using parameters such as pH.

## Features
- Loads and explores a water potability dataset (CSV)
- Analyzes water quality parameters using Pandas and NumPy
- Visualizes trends with Matplotlib
- Shows water quality results and alerts in the notebook

## Technologies Used
Python, Pandas, NumPy, Matplotlib, SQLite, Google Colab

## How to Run
1. Download `miniproject_.ipynb` from this repository.
2. Open it in Google Colab or Jupyter Notebook.
3. Upload the dataset file `water_potability.csv`.
4. Run all the cells in order.
